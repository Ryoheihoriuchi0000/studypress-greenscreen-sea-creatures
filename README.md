# Studypress sea creatures

89 sea creature video clips with transparent backgrounds. 82 of them were finished for the [Studypress](https://apps.apple.com/jp/app/id6811388420) app.

All clips are AI-generated with Google Flow. They are not filmed footage.

**Preview and download every clip: <https://alpha-zoo.vercel.app>**

## Files

Each creature in `videos/` has four files:

| File | Format |
|---|---|
| `<name>.mov` | HEVC with alpha, for Apple devices |
| `<name>.webm` | VP9 with alpha |
| `<name>_loop.webm` | VP9 with alpha, with the ends blended for looping |
| `<name>.png` | Still image with alpha |

`SHA256SUMS` has checksums for every file.
